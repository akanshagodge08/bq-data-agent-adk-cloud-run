# BigQuery Data Agent on Cloud Run

An AI data agent built with Google's Agent Development Kit (ADK) and Gemini. It explores the NYC Citi Bike dataset in BigQuery, writes its own read-only SQL, and gives data-backed business recommendations. Deployed on Google Cloud Run.

## Tech Stack
ADK, Gemini (Vertex AI), BigQuery MCP, Cloud Run, Cloud Build, Artifact Registry

## Deploy
adk deploy cloud_run with the --with_ui flag (see Google Cloud codelab)
